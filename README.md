# WizardWarBuild

// How to access

1.) Go to the github-pages page under Deployements

2.) Open the active deployement (with the green check) which will redirect you to a new page of the WebGL build

3.) Add to the end of the URL v1.0/index.html 

// How to play

Instructions available in in-game main menu screen.

Tip: Patience wins!
